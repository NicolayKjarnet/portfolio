Discover Munch

Project Summary

The Discover Munch app leverages modern technology to create an engaging museum experience. With AR and QR code functionalities, users can enjoy interactive tours and gain detailed insights into Munch's artworks, guided by the virtual character, Mr. Scream. The app includes a QR scan solution for accessing artwork information and an admin page for efficient content management.

Project Process

1. Research

We began by researching the museum's challenges in attracting young visitors and identifying modern technology solutions that could enhance engagement. Our focus was on implementing QR codes to create a more interactive and informative experience.

2. Concept Development

Our concept aimed to motivate young adults to visit the museum more frequently. We designed a QR code system that allows visitors to access detailed information about the artworks, enhancing the overall museum experience.

3. Prototyping

Using Figma, we created prototypes to visualize our ideas. Initial prototypes focused on QR code functionalities, which were refined based on feedback. The final prototype included interactive elements and a realistic representation of the app's features.

4. QR Solution Implementation

The QR solution was implemented using React Native, allowing users to scan QR codes and access detailed artwork information. This feature also lets users save their favorite artworks and track their museum visits.

5. Admin Page Development

We developed an admin page using React and .NET/C#, enabling museum staff to manage artwork information efficiently. This system supports CRUD operations and ensures the content displayed in the app is accurate and up-to-date.

6. User Testing and Feedback

Prototypes were tested with the target audience to gather feedback on the app's functionality and usability. Based on the feedback, we made necessary adjustments to improve the user experience and ensure the app met the needs of our target audience.
