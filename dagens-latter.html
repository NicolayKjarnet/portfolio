Laughter of the Day

Project Summary

This is a basic iOS app using an external API to fetch a random joke and Core Data to save the jokes. The app has full CRUD functionality: create your own jokes, save them, edit them, and delete them. The app also has rating functions, filtering functions and a search function. The app is built using Swift.
