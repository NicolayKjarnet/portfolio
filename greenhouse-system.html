Greenhouse System

The Greenhouse Monitoring System is an advanced solution designed to optimize the growth conditions of various crops by leveraging a combination of sensors and IoT technology. This system is implemented using Arduino and a suite of sensors from Adafruit, including temperature, humidity, and light sensors.

GitHub Repository

Key Features:

  • Temperature and Humidity Monitoring: The system continuously monitors the temperature and humidity levels using the Adafruit SHT31 sensor. It alerts the user if these parameters fall outside the optimal range for crops.
  • Light Intensity Management: The light intensity is monitored using the Adafruit LTR329 sensor. The system ensures that crops like Cayenne Pineapples and Goldfinger Bananas receive the appropriate amount of light. Alerts are generated if the light is too dim or too bright.
  • Magnetic Door Sensor: A hall sensor is used to detect the status of the greenhouse door. Alerts are sent if the door remains open for too long, ensuring the greenhouse environment remains controlled.
  • IoT Connectivity: The system uses WiFi to connect to the internet, sending data to a remote server for analysis and long-term storage. This allows users to monitor greenhouse conditions in real-time from anywhere.
  • Push Notifications: Users receive immediate alerts on their mobile devices via Pushsafer when conditions require attention, such as extreme temperatures, humidity levels, or prolonged door openings.
  • Data Integration: The system integrates with the OpenWeatherMap API to provide weather updates and contextual information about external conditions, enhancing the decision-making process.
