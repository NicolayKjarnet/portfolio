# Personal Portfolio

Personal portfolio website showcasing frontend development, interactive design, and content production work.

Live site: [nicolaykjaernet.com](https://nicolaykjaernet.com)

## Tech

Vanilla HTML, CSS, and JavaScript. No build tools or frameworks required.

Structure:
- `index.html` — main entry point
- `css/` — stylesheets
- `scripts/` — JavaScript files
- `images/` — image assets
- `videos/` — video assets
- `audio/` — audio assets

## Running locally

Open `index.html` directly in a browser, or serve it with a local server:

```bash
npx serve .
```
